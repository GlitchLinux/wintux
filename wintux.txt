To get at your Windows files inside this VM:

  mnt-win                   # prompts for Windows user + password
  mnt-win <user> <pass>     # non-interactive, mounts //10.0.2.2/WinShell
  mnt-win --save            # remember creds; auto-mount on next boot
  mnt-win --umount          # unmount /mnt/win

First time only, on the Windows side (admin cmd):

      net share WinTux="%USERPROFILE%" /GRANT:%USERNAME%,FULL

Raw-attached disks (secondary disks the launcher passed to the VM) show
   up as /dev/vd? and mount with ntfs-3g directly.

This is an ephemeral VM. Anything in / disappears on shutdown. Only
writes under /mnt/win reach Windows.
